# 教育ウォッチ
文部科学省の教育課程情報を読む個人学習用サイト。

教育課程企画特別部会・総則／評価特別部会・文部科学省新着情報から関連資料を収集し、調整授業時数制度・サキドリ研究校の参考資料と一緒に表示します。

- テーマ検索、あとで読む、読了、資料ごとの学習メモ
- 学習記録はブラウザのlocalStorageに保存。JSONで書き出し・読み込みができます。
- 会議開催日と公表日を区別。制度の確定状況は公式資料で確認してください。
- GitHub Actionsが毎時17分に収集してGitHub Pagesへ公開。実行の遅延があり得るため画面の収集日時を確認してください。
- 全情報源の取得が失敗した場合は前回の公開を維持。一部の失敗は画面に表示します。
- 定期処理のデータは公開サイトへ配信。リポジトリのJSONは初期取得時点の記録です。
- 通知はチャットの定期確認で別途行います。

更新：`node scripts/update-news.mjs`（Node.js 24・curl、追加パッケージ不要）
公開ファイル：`docs/`
GitHub Pagesの公開元はGitHub Actionsに設定してください。
